# سورس کد لئون گلد (۱۴۰۵/۰۸/۲۵)

| پوشه | چیست |
|---|---|
| leon-gold | دفتر لئون (یک فایل index.html) و ساخت نسخه‌ی گوشی |
| leon-gold-site | سایت leongold.net، «حساب من» و پنل CRM (Next.js) |
| leon-gold-server | سرور api.leongold.net (Node + SQLite)؛ سینک دفتر، «حساب من»، آبشده |
| leon-gold-app | نسخه‌ی ساخته‌شده‌ی دفتر برای گوشی (GitHub Pages) و خبرخوان قیمت |
| leon-gold-hosting | ساخت کل سایت برای دامنه |
| leon-gold-social | برنامه و طرح‌های اینستاگرام |
| leon-gold-android / windows / mac | اپ‌های «حساب من» |

فقط کدِ ثبت‌شده در گیت است. داخلش نیست: دیتابیس و پشتیبان‌ها، اطلاعات مشتری، رمزها و کلیدها، فایل‌های نصبی (node_modules) و خروجی‌های ساخته‌شده (اپ‌ها، سایت ساخته‌شده).
«روتین من» (لئون جیم) جدا شده و در projects/leon gym است.
